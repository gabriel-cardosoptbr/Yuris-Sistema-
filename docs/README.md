Inovaize CRM — Documentação

Propósito
- Reunir documentação do CRM para apresentação e referência.

Conteúdo desta pasta
- FEATURES.md — Lista de funcionalidades e casos de uso.
- PAGES.md — Páginas público/privadas e suas responsabilidades.
- API.md — Endpoints públicos do backend e comportamentos.
- ARCHITECTURE.md — Visão geral da arquitetura do sistema.
- PRESENTATION.md — Roteiro de apresentação / slides sugeridos.

Como usar
- Abra os arquivos nesta pasta para montar sua apresentação.
- Para adicionar diagramas, inclua imagens na pasta docs/assets e referencie-as neste README.
