================================================================================

     * HttpOnly: true
     * SameSite: Lax
     * Secure: auto-detect HTTPS (não quebra dev local)

   - Tabela login_attempts criada (ip, login, success, created_at)

     (mesmo IP + mesmo login)

   - Falha silenciosa se tabela não existir (resiliência)

✅ .HTACCESS BLOQUEANDO DIRETÓRIOS SENSÍVEIS
   Criados:
   - /config/.htaccess     — bloqueia database.php, .env, etc.
   - /storage/.htaccess    — bloqueia logs e cron locks
   - /app/.htaccess        — bloqueia Controllers/Models/Helpers/Services
   - /database/.htaccess   — bloqueia migrations/seeds

   Funciona com mod_authz_core (Apache 2.4+) E fallback pra mod_access
   (Apache 2.2). Não precisa do mod_rewrite.

✅ OPCACHE_CLEAR.PHP RESTRITO A ADMIN
   - Antes: qualquer usuário logado podia acessar
   - Agora: 403 se !owner && !admin && !perfil=admin

✅ TIMING-SAFE COMPARISONS
   - webhook.php usa hash_equals() em vez de === pra comparar apikey
     (evita timing attack)
